## 🚀 Key Cyberpunk Features

### 1. 🧬 CodeDNA Heuristic Scanner
*   **Static Genomic Analyzer** — Meticulously profiles compiler attributes (loop densities, recursion depths, JavaScript chain functions, code/comment ratios, and casing styles).
*   **Double-Helix 3D Canvas** — Renders segment-by-segment pink (`#FF2D78`) and green (`#00FF88`) sine waves with mouse-controlled rotation speed, neon node pulses, and base-pair mutations.

### 2. 🌳 RPG DSA Skill Tree Page
*   **15-Node Interactive spring layout** — Dynamic coordinate SVG talent hierarchy leading from fundamental topics (Hashing, Arrays, Strings) to advanced concepts (BFS/DFS, Dijkstra, DP).
*   **Glowing Hexagon Nodes** — Real-time tracking badges indicating Locked, Unlocked (ready to master), Active, and Mastered levels.
*   **Interactive Particle overlay** — High-performance HTML5 canvas firework bursts triggered at 60 FPS upon leveling.

### 3. ⚔️ 1v1 Live Code Battles
*   **Real-time Matchmaking** — Synchronized via Firebase Realtime Database. Select difficulty (Easy, Medium, Hard) to automatically match active room contenders.
*   **Contender splitscreens** — Shared countdown timers, character count indicators, live text chat blocks, victory celebration canvas grids, and instant spectator channels.

### 4. 💀 AI Ghost Mentor stuck-assistant
*   **Stuck triggers** — Silently monitors solving states. Triggers when developers are idle on the same line for 90s, log 3+ consecutive Wrong Answers, or duplicate-delete codes.
*   **Talking pixel-art skull SVGs** — Features breathing pixel-art skull meshes that reveal Google Gemini-powered typewriter hints on demand.

### 5. 🎬 Code Replay Theatre
*   **Timeline session recorders** — Automatically tracks Monaco character stroke timestamps, capturing speed accelerations and code hesitation pauses.
*   **Interactive scrubbers** — Timeline scrub bar showing event overlays (checks, hesitations, accepted compiles). Include comment nodes linked directly to individual timeline seconds.

### 6. 🕸️ Genomic Skill Radar Chart
*   **8-Axes Octagonal grid** — Custom concentric drawing layout mapping developer mastery (Arrays, DP, Graphs, Backtracking, etc.).
*   **Dynamic comparisons** — Compare and contrast ratings with friends, pre-contest profiles, and top-tier global benchmark metrics.

### 7. 👹 Daily Boss Battle Raid
*   **10,000 HP World Raid Bosses** — Global community monsters syncing health gauges live using Firestore `onSnapshot`.
*   **Heuristic damage counters** — Translates solved complexity algorithms into weapon strikes. (Optimal O(N) = 300, Critical speeds = 500). Includes screenshakes and floating text damage points.

### 8. 🎙️ Voice Thought Debugger
*   **Speech-to-Code mapping** — Continuous vocal dictation mapped directly to active cursor line-numbers.

### 23. 📡 Automated LeetCode Scraper & Weekly Sync Pipeline
*   **Differential Fetch Engine** — Only scrapes newly added LeetCode problems, using a local cross-run cache file (`problem_details.json`) to skip existing docs.
*   **HTML Cleaners & Normalizers** — Converts complex nested HTML templates into clean Markdown, normalizes 30 competitive tags, and maps 10 starter code structures.
*   **Automatic Cron Job Sync** — Runs on GitHub Actions every Sunday at midnight, executing a multi-step sequence to fetch, transform, enrich, and batched-upload (O(500) items per commit) into Firestore.

## ⚙️ Getting Started

### 1. Clone & install
```bash
git clone https://github.com/balajiynspk-alt/Code-Arena.git
cd codearena
npm install
```

### 2. Configure environment variables
Copy `.env` to `.env.local` and fill in credentials:
```env
REACT_APP_FIREBASE_API_KEY=your_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_domain
REACT_APP_FIREBASE_PROJECT_ID=your_id
REACT_APP_FIREBASE_STORAGE_BUCKET=your_bucket
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=your_id
REACT_APP_FIREBASE_APP_ID=your_app_id
REACT_APP_GEMINI_KEY=your_gemini_key
```

### 3. Setup Weekly Problems Sync (Optional CI/CD)
To sync new LeetCode challenges automatically:
1. Go to your GitHub Repository → **Settings** → **Secrets and variables** → **Actions**.
2. Click **New repository secret**.
3. Name: `FIREBASE_SERVICE_ACCOUNT`
4. Value: Paste the entire content of your Firebase `serviceAccountKey.json`.

### 4. Start the dev server
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) to enter the arena.
